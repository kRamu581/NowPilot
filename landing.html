Capabilities

Six places, one safe control plane.

Chat, ITSM intelligence, Dev Assistant, workflows, seals, and your own models — all inside ServiceNow, all behind human Accept.

I

Context-aware chat

Floating panel across forms and Next Experience. Reads the open record via g_form — no bulk data dump.

II

ITSM intelligence

Similar resolved incidents, published KB only, citation checks so models can’t invent ticket numbers unnoticed.

III

Dev Assistant + DevValidator

Generate Business Rules and Script Includes with static guards that block current.update() and eval().

IV

Agentic workflows

Plan multi-step work. Reads run; writes become proposal cards. Pause, approve, resume — reload-safe.

V

GMGSeal integrity

HMAC-SHA256 sealed proposals, stale-record detection, replay protection. The model never touches tables directly.

VI

Your models, your keys

Claude, OpenAI, Grok, Gemini, OpenRouter, Ollama, vLLM — same agent, different backends.

Quick start

Up and running in minutes.

Try the local simulator first. Deploy to ServiceNow when you’re ready — clear 11-step guide included.

1. Local sandbox (no instance)

Full mock panel and APIs on your machine.

git clone https://github.com/kRamu581/NowPilot.git
cd NowPilot
node local_runner.js
# open http://localhost:3000
Clone on GitHub Read README

2. ServiceNow instance

Written for admins new to update sets.

  1. Import global XML → Preview → Commit
  2. Import scoped XML → Preview → Commit
  3. Assign role x_gmg_ai.user, log out / in
  4. Add one provider (OpenAI, Claude, Gemini…)
  5. Open an Incident and click the launcher
